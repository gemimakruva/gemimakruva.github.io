3. MAINTAINABILITY 100% KELUAR

Maintainability = design characteristic (di-design). Maintenance = operational activity (dilakukan).

3 Tujuan:

  1. Minimasi system downtime (MDT)
  2. Maksimasi Ao = MTBM / (MTBM + MDT)
  3. Reduksi biaya maintenance (O&S = 60–80% LCC)

3 Level Maintenance:

LevelLokasiAktivitas
OrganizationalLapanganInspeksi rutin, ganti modular, cleaning
IntermediateWorkshopKalibrasi, component repair
DepotPabrik/OEMOverhaul besar, rebuild, remanufacture

6 Elemen Desain Maintainability:

  1. Accessibility — akses fisik komponen
  2. Testability — kemudahan diagnosis/deteksi
  3. Standardization — interchangeability parts
  4. Modularization — plug-in/remove tanpa tool khusus
  5. Labeling — identifikasi jelas
  6. Simplification — minimalkan step & tools

10 Ukuran Maintainability:

Mct, Mpt, M̄, MDT, λm, MTBM, maintenance manhours/ophr, turnaround time, logistics delay, admin delay

FORMULA KUNCI
Reliability: R(t) = e−λt   θ = MTBF = 1/λ
Seri: Rs = R1×R2×…×Rn
Paralel: Rp = 1−(1−R1)(1−R2)…(1−Rn)

Ai = MTBF / (MTBF + Mct) — inherent
Aa = MTBM / (MTBM + M̄) — achieved
Ao = MTBM / (MTBM + MDT) — operational
MDT = Mct + Mpt + logistic delay + admin delay

FTA: AND = P(A)×P(B)   OR = P(A)+P(B)−P(A)×P(B)
RPN = Severity × Occurrence × Detection
BEP = Fixed Cost / (Revenue/unit − Variable Cost/unit)
4. HUBUNGAN HF ↔ RELIABILITY ↔ MAINTAINABILITY 100%
HubunganMekanismeContoh
HF→RelHF buruk → human error ↑ → λ ↑ → R ↓Cockpit ergonomis → pilot error ↓ → insiden ↓
HF→MaintAkses sulit → Mct ↑ → MDT ↑ → Ao ↓Panel sempit → teknisi 4 jam bukan 30 menit
Rel→MaintR rendah → maintenance sering → biaya ↑MTBF 100jam → maint tiap 4 hari
Maint→RelMaint buruk → degradasi → R ↓Over-torque saat service → premature failure
Ao = MTBM / (MTBM + MDT)
MTBM dipengaruhi Reliability (R↑ → MTBM↑). MDT dipengaruhi Maintainability (desain mudah → MDT↓). Keduanya dipengaruhi HF (ergonomis → human error↓).
5. DISPOSABILITY & SUSTAINABILITY 100%

Disposability:

  • % material recyclable
  • Biaya disposal per unit
  • Waktu dekomisioning
  • Compliance regulasi lingkungan
  • Disposal cost % dari total LCC

Sustainability:

  • Carbon footprint (kg CO2 eq)
  • Energy efficiency (output/input)
  • % material ramah lingkungan
  • Water & waste per unit output
  • Life cycle assessment (LCA) score

7. FTA vs FMEA vs RCM
MetodeArahPendekatanOutput
FTATop-downMulai dari system failure → cari root causesFault tree, cut sets, probabilitas
FMEABottom-upMulai dari komponen → identifikasi failure modesRPN = S×O×D, corrective actions
RCMFunction-basedFungsi → functional failure → strategi optimalMaintenance strategy per komponen

FTA gates: AND (semua harus gagal) = P(A)×P(B). OR (salah satu cukup) = P(A)+P(B)−P(A)×P(B). RPN: prioritaskan tertinggi untuk corrective action.

11. 7 PRINSIP SE
  1. Top-down life-cycle — level sistem dulu, turun ke detail
  2. WHAT before HOW — definisikan kebutuhan sebelum solusi
  3. Interdisciplinary team — semua disiplin sejak awal
  4. Iterative with feedback — synthesis-analysis-evaluation berulang
  5. Multiple criteria — jangan optimasi satu parameter saja
  6. Requirements traceability — customer need → komponen
  7. Early decisions matter most — 70–80% LCC terkunci di awal
12. FRAMEWORK STUDI KASUS

Soal studi kasus selalu berupa kasus baru. Gunakan framework ini:

  1. Identifikasi masalah — apa yang gagal/perlu diperbaiki
  2. Analisis kebutuhan — operational requirements (7 komponen)
  3. Kaitkan dengan SE concepts — 3 fase design, T&E, -ilities
  4. Analisis teknis — FTA/FMEA/RCM, reliability, maintainability
  5. Solusi & rekomendasi — design changes, trade-offs
  6. Evaluasi LCC — cost-benefit dari solusi yang diusulkan

Tools yang sering diminta: FTA (top-down untuk safety-critical), FMEA (bottom-up per komponen), RCM (optimasi strategi maintenance).
